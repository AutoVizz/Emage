0. Server connection

Read-side requests need no upload password. Leave the base URL empty to call the API same-origin (e.g. when this page is served by the Emage server itself). Cross-origin fetches from another port/scheme are subject to browser CORS; the layer-window API currently sends no CORS headers.

1. Decryption key

AES Key (hex, 32 bytes):
AES IV (hex, 16 bytes): carried in the SEC marker; nothing to paste
Access level (highest readable level, 0 = coarsest; blank = all):

The master key derives one key per DWT resolution level (K0 = key, K1 = SHA3-256(K0), ...). This is the highest level you hold: with K0..Ka the client requests only levels 0..a from the server and decodes no finer than that. A finer request is clamped rather than satisfied with an approximate image.

2. Image browser (virtual filesystem)

- awaiting listing: press "Refresh listing" -

Image paths are shown like files under a virtual root. Folders are derived from the path components, so sub/dir/photo.j2k appears in sub/dir/. Click a folder to descend; click a file to prepare it for loading, or double-click to start a progressive load.
