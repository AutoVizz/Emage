2. Results

All three columns fetch the same codestream in the same single request: resolution levels are spatially nested, not bandwidth-separable, so a reduced-resolution decode still needs every byte. They differ only in which DWT levels the decoder is asked for. Decoding level r means ceil(W / 2NL-r) square, so the decoder never MQ-decodes the code blocks above r and never runs the high-pass synthesis path on them. A walks from two levels coarser than the target down to it, so its intermediate frames are a quarter the samples of the next one and cost a small multiple of the final decode in total. B decodes only the target level. C is the old behaviour: full resolution regardless of the size target, kept as the baseline. The three runs are sequential, each timed from its own start.
