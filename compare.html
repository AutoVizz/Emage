2. Results

metric progressive full (all) verdict

Progressive fetches the main header once, then one window per quality layer, appending packets and decoding a frame at each step. Full fetches headers + all packets in a single response. Both loads run in parallel from the same start time, so the fetch timings are collected under identical network conditions; the full payload's decode runs after the progressive pipeline finishes painting, so a long synchronous decode can't skip the intermediate progressive frames. When a display size limits the progressive side, its frame is compared at that size (full raster downscaled) rather than at full resolution.
